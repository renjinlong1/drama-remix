【枫的瞬剪 · 便携版】新电脑使用说明
========================================

这个压缩包是"绿色软件"：不用安装 Python、不用联网，解压就能用。
画面识别字幕（OCR）、剪辑引擎、ffmpeg 全都打包在里面了。

怎么开始
--------
1. 把整个 zip 解压到任意位置（建议 D 盘或桌面，路径最好不含特殊符号）
2. 打开解压出来的 drama-remix 文件夹
3. 双击「启动.bat」——会弹出一个黑色窗口（这是服务本体，别关）
   一两秒后浏览器会自动打开枫的瞬剪
4. 用完把黑窗口关掉就是退出

第一次用建议先做一次导入：把一部剧的文件夹拖进去（或点导入选文件夹），
勾上「画面硬字幕识别」可以在没有字幕文件时自动 OCR。

把旧电脑的项目搬过来（可选）
--------
这个包里【没有】带任何项目存档，解压后是干净的：最近项目是空的，
导入哪部剧就只认哪部剧，不会冒出上一台电脑的剧。

如果确实要从旧电脑接着剪，把这三样连同原片一起拷过来：
- projects\   各部剧的项目文件（.json）
- data\       OCR 字幕缓存等
- output\     已经剪出来的成片

注意：项目文件里记的是【旧电脑上的原片绝对路径】（比如 F://素材//某剧）。
新电脑上如果没有一模一样的盘和目录，枫的瞬剪会：
- 启动时【不会】自动打开这些项目（避免一进来就是一屏黑缩略图）；
- 在「最近项目」里把它们标成橙色的「路径失效」；
- 点它之前会提醒你原片不在这台电脑上；
- 标题栏下方会出现一条橙色警告条，写清缺的是哪个路径。
这时候两条路：
  a) 原片也在新电脑上 → 点右上「＋ 新建」，重新选一次那个文件夹导入
     （字幕缓存会命中，重新导入很快）；
  b) 不要这些旧项目了 → 在「最近项目」标题右边点「清理失效」，一键清掉
     （只删项目存档，原片和字幕缓存都保留）。

想彻底搬一次家（连项目一起），最稳的做法是：新电脑上先按原路径把原片放好
（比如都放在 F://素材//），再把 projects 和 data 拷过去，路径对得上就能直接打开。

常见问题
--------
· 双击「启动.bat」闪退：
  先看黑窗口里的报错。最常见是杀毒软件拦了内置的 Python / ffmpeg，
  把 drama-remix 文件夹加入白名单再试。
· 最近项目里出现橙色的「路径失效」：
  说明那些项目记的原片路径在这台电脑上不存在（从旧电脑带过来的存档）。
  点「清理失效」清掉即可；要用原片就重新导入一次。
· 双击「启动.bat」提示"已经在运行"：
  正常，枫的瞬剪服务已经在后台跑着，它会直接帮你打开浏览器。
· 浏览器没自动开：
  手动打开浏览器访问 http://127.0.0.1:8780
· 换端口：
  修改「启动.bat」，在 python app.py 上一行加
  set DC_PORT=8790
· 依赖坏了想重装：
  双击「安装依赖.bat」（需要联网，只在包内组件损坏时才用）。

配置要求
--------
Windows 10/11 64 位；剪 4K 素材或跑画面识别时建议 16G 内存。
不需要独立显卡，不需要联网。
