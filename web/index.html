三步出片

  1. 导入：把一部剧的所有分集和字幕放在一个文件夹，粘贴路径（或点「选择…」），填剧名，点「扫描并分析」。工具会读台词、切节拍、算冲突分。
  2. 选钩子：右侧「高光钩子候选」一次给出 15-20 个片段，按抓人程度排序，每张卡左上角标着它是哪种高光——动作冲突（扇巴掌、泼酒、摔杯子、推人、当众下跪这类动手镜头）、爆发点（哭喊、重音、情绪炸开）、台词冲突（打脸、退婚、滚出去）、身份反转、悬念留扣。点一个就作为开头。位置差半秒就这样修：鼠标移到卡片上，缩略图左右的 ‹ › 把整段往前 / 往后挪 0.5 秒（按住 Shift 挪 2 秒），最多贴到集首/集尾，挪完时间精确到 0.1 秒并标出挪了多少；结尾候选同样能挪，选中后挪也照样是选中状态。不想要的按卡片右上角 ✕ 从候选里删掉（点「恢复原样」能找回来，挪过的位置也一并还原）；识别漏了的好镜头，点「＋ 手动加」，选集数、填起止秒数（支持 1:30 这种写法）就能自己加一条。顶上的「全部 / 动作冲突 / 台词冲突」可以筛着看。也可以不设钩子，直接从头顺剪。
  3. 定结尾：默认由算法在目标时长附近挑最好的结束点——优先卡在某一集结尾（短剧每集末尾本来就埋着钩子），其次看这句话本身有没有悬念。想强制停在某处，就到「结尾钩子候选」点一个，再点一次取消。
  4. 调与出片：拖「目标时长」定在 3-8 分钟，顺剪区间和结束位置会实时更新；时间轴上点方块可以把某句挖掉（再点恢复）；填好剧名、logo、App 名和引导语，点「开始顺剪出片」。出片前先点「预览成品（不出片）」：按当前方案把每段原片按顺序播一遍，开头第一帧、每个切点、收尾停的位置、尾帧停多久都和成片一致，不用等转码。如果扇巴掌、下跪这些动作比台词早出现，把「顺剪设置」里的 开头入戏 调大（默认提前 1 秒），预览和成片会一起往前挪。去尾帧（默认自动识别）会把每集末尾的平台片尾卡切掉，免得集与集之间割裂——识别不到就不裁（也可以改「固定秒数」或「不去」）；它只切集与集的接缝，成片最后一段和你上传的引导尾帧都不动。

顺剪逻辑：开头钩子 → 从这一集这段往后连续顺接（第 1 集剩余 → 第 2 集 → 第 3 集 → 第 4 集……）→ 时长够了就停在最抓人的地方 → 引导尾帧。正片是连续播放的，不按台词挑镜头——剧本里没有台词的那几十秒往往正是剧情在演。结束点会自动打分：集末卡点加分最多，其次是句子本身带悬念（没回答的问句、真相、你等着…），再减去离目标时长的偏差。如果某集结尾本身就是个好卡点，成片就停在那里。

批量产出：在每个高光开头卡片右下用「− N +」设定要出几条，选好多个开头后点「开始批量出片」。同一开头的第 1 条是标准方案，第 2 条起会换一个结尾候选、再剪几处较长的空镜，时长仍贴近目标——结构一致但画面确实不同，降低平台查重风险。想亲手定结尾，点出片数量下面那行的「指定每条的结尾…」：每个开头、每条成片都有一个下拉框，可以从这个开头能用的结尾候选里挑一个（也有「按候选顺序分配」一键铺开），保存后出片就精确停在那个点。包装、文案对所有条目相同。出片命名：剧名_开头01_02.mp4。

原声保留并统一到 -16 LUFS。成片只有三段：开头钩子 → 连续正片 → 引导尾帧，不再生成片头剧名卡和结尾追更卡，要加的剧名、logo、追更引导都放在你自己的「引导尾帧」和「包装模板」里。上传「引导尾帧」后会在片尾播放——传 png 按设定秒数停留，传做好的 mp4 则按视频原时长整段播放并保留其声音（「尾帧 __ 秒」只对图片生效）；「包装模板」是全屏透明 png，会整片叠加，可调不透明度。
